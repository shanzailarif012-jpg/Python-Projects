# 🐍 Python Projects

Welcome to my **Python Projects** repository! 🚀

This repository contains a collection of Python projects built during my learning journey to improve programming, problem-solving, and Object-Oriented Programming skills.

## 📂 Projects

### 🎮 1. Snake, Water, Gun Game
A command-line game where the player competes against the computer.

**Concepts:** Dictionaries, Functions, User Input, Random Module, Conditional Logic, Game Logic

---

### 🎯 2. The Perfect Guess
A number guessing game where the player tries to guess a randomly generated number between 1 and 100.

**Concepts:** Loops, Conditionals, User Input, Random Module, Game Logic

---

### 🏦 3. Bank Account Management System
A command-line banking system built using **Object-Oriented Programming (OOP)** with account creation, deposits, withdrawals, PIN authentication, and transaction history.

**Concepts:** OOP, Classes, Constructors, Encapsulation, Dictionaries, Loops, Input Validation

---

### 📚 4. Library Management System
A command-line library system built using **OOP** for managing books, multiple copies, issuing and returning books, searching the catalog, and tracking student borrowing records.

**Concepts:** OOP, Classes, Encapsulation, Dictionaries, Lists, Loops, String Methods, Input Handling

--- 

### 🎓 5. Student Result Analyzer
This project allows users to add students, store their marks, calculate total and average marks, assign grades, check pass/fail status, display all students, find passed students, and identify the top-performing student.

**Concepts:** Object-Oriented Programming (OOP), Classes & Objects, Constructors, Instance Methods, Type Hints, List Comprehension, match-case, try-except, raise ValueError, enumerate(), Built-in functions like sum() and max()

---

### 🎫 6. Fast Ticket Booker
A command-line ticket booking system for booking Bus, Train, Car, and Van tickets across three travel classes, with automatic train discounts, unique ticket IDs, saved receipts, and full booking history.

**Concepts:** Modular Programming (multi-file structure), Functions, Dictionaries, File Handling (.txt & .json), JSON Module, datetime Module, uuid Module, Input Validation, os Module

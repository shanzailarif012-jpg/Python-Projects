# 🎯 The Perfect Guess

A simple Python number guessing game where the computer generates a random number between **1 and 100**, and the player must guess it using the provided hints.

## 🚀 Features

- Random number generation
- Higher/Lower hints
- Attempt counter
- Simple and interactive gameplay

## 🛠️ Technologies Used

- Python 3
- Random Module

## ▶️ Run

```bash
python main.py
```

## 📚 Concepts Used

- Loops
- Conditionals
- User Input
- Random Module

# 📂 Project 1: Snake, Water, Gun Game

A command-line **Snake, Water, Gun** game built with Python where the player competes against the computer.

## 🚀 Features
- Random computer choice using the `random` module
- User input for player moves
- Winner determination using game rules
- Conditional logic (`if`, `elif`, `else`)
- Play Again option
- Winner announcement

## 🛠️ Concepts Practiced
- Python Dictionaries
- User Input
- Random Module
- Conditional Statements
- Game Logic
- Functions

## 🎯 What I Learned

This project strengthened my understanding of Python fundamentals by implementing game logic, handling user input, working with dictionaries, and using conditional statements to determine the winner.
